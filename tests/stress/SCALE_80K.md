# Stress test 80.000 χρηστών — 2026-09-30

> Τι είναι μετρημένο και τι προσομοίωση φαίνεται σε κάθε ενότητα. Δεν έγινε ΚΑΝΕΝΑ πραγματικό αίτημα προς GitHub Pages / Google / Anthropic.

## A. Βάρος σελίδας — ΜΕΤΡΗΘΗΚΕ (gzip, όπως το σερβίρει το GitHub Pages)
| Τι | gzip | πότε φορτώνεται |
|---|---|---|
| Εφαρμογή (8 αρχεία: index + 7 modules) | 40.0 KB | σε κάθε πρώτη επίσκεψη |
| Βιβλιοθήκη PDF (html2pdf) | 256.8 KB | μόνο όταν φτιαχτεί 1ο PDF |
| Anthropic SDK | 52.7 KB | μόνο αν ο χρήστης έχει key Anthropic |

Πρώτη επίσκεψη με PDF: 296.8 KB ανά χρήστη → **22.6 GB** για 80.000 χρήστες (χωρίς cache, χωρίς Google Fonts).
Το GitHub Pages έχει **soft όριο 100 GB/μήνα** (docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) → 4.4 τέτοια «κύματα» χρηστών τον μήνα μέχρι να ξεπεραστεί· στις επόμενες επισκέψεις ο browser χρησιμοποιεί cache.
Αιτήματα προς το hosting: 8 αρχεία ανά πρώτη επίσκεψη (+1 για το PDF) → αν και οι 80.000 έρχονται μέσα σε 1 λεπτό: ≈ 12.000 αιτήματα/δευτ. σε στατικά αρχεία (CDN· ΔΕΝ μετρήθηκε — δεν φορτώνουμε τρίτο).

## B. CPU στη συσκευή του κάθε χρήστη — ΜΕΤΡΗΘΗΚΕ (parser, Node· το κινητό είναι πιο αργό)
80.000 αναλύσεις κειμένου σε 6.47 s σε ΕΝΑ νήμα → μέσο 81 µs, p95 186 µs, max 3.26 ms.
Κάθε χρήστης το τρέχει στο δικό του κινητό: το κόστος δεν προστίθεται σε κάτι κοινό. Δεν υπάρχει server ή βάση μας που να φορτώνει.

### Χειρότερη περίπτωση ανά χρήστη (δείγμα 2.000 χρηστών, ο καθένας με ΔΙΚΗ του συνεδρία, provider που απαντά συνέχεια 429 ή 503)
- **όλα 429**: 20.000 κλήσεις από 2.000 χρήστες → μέσο 10.0 κλήσεις/χρήστη, **μέγιστο 10**. Δηλαδή το πολύ 10 κλήσεις ανά χρήστη (όριο της πολιτικής) → για 80.000 χρήστες ≤ 800.000 κλήσεις προς τον provider. Ο χρήστης βλέπει: «Έφτασες το όριο της Google. Δοκίμασε ξανά σε 20 δευτερόλεπτα.».
- **όλα 503**: 20.000 κλήσεις από 2.000 χρήστες → μέσο 10.0 κλήσεις/χρήστη, **μέγιστο 10**. Δηλαδή το πολύ 10 κλήσεις ανά χρήστη (όριο της πολιτικής) → για 80.000 χρήστες ≤ 800.000 κλήσεις προς τον provider. Ο χρήστης βλέπει: «Οι servers της Google είναι φορτωμένοι αυτή τη στιγμή — δεν φταίει το key σου. Δοκίμασε ξα».
