# 5 συζητήσεις με τεχνίτες — πριν από νέο κώδικα

Σκοπός: να μετρηθεί αν υπάρχει πρόβλημα που αξίζει να λυθεί. Όχι παρουσίαση της εφαρμογής πριν από τις ερωτήσεις.

**Κύρια μετρήσιμη ερώτηση:** «Την τελευταία φορά που έβγαλες προσφορά, πόσα λεπτά σου πήρε από τη στιγμή
που είδες τη δουλειά μέχρι να φτάσει στον πελάτη; Με ποιο εργαλείο την έφτιαξες;»

Για κάθε συζήτηση καταγράφεται:

| Πεδίο | Τιμή |
|---|---|
| Ειδικότητα / πόσα άτομα στο συνεργείο | |
| Προσφορές τον μήνα | |
| Χρόνος τελευταίας προσφοράς (λεπτά) — με δικά του λόγια, όχι εκτίμηση «συνήθως» | |
| Εργαλείο (χαρτί, Excel, Word, πρόγραμμα, WhatsApp, τίποτα) | |
| Από πού παίρνει τιμές υλικών | |
| Πόσες προσφορές χάνει επειδή αργεί να τις στείλει (αν ξέρει) | |
| **Πράξη (ναι/όχι):** δέχεται να φτιάξει την επόμενη πραγματική του προσφορά με το demo, με τον Νίκο δίπλα; | |
| Αν ναι: χρόνος με το demo (λεπτά, μετρημένος) και αν η προσφορά στάλθηκε στον πελάτη | |
| Αν ναι: σε πόσες από τις γραμμές άλλαξε την τιμή (π.χ. 7 / 9) — αν στις περισσότερες, το εμπόδιο είναι ο τιμοκατάλογός του και όχι η ταχύτητα (→ το onboarding τιμών είναι μέρος του προϊόντος) | |
| Θα πλήρωνε; Πόσο; (μόνο στο τέλος, χωρίς να προταθεί ποσό — **αδύναμο σήμα**, οι υποθετικές απαντήσεις για πληρωμή υπερεκτιμούν· δεν μετράει στο κριτήριο) | |

## Κριτήριο συνέχειας

**ΑΝΟΙΧΤΟ — απόφαση του Νίκου.** Συμπληρώνεται εδώ και γίνεται commit **πριν από την 1η συζήτηση**· μετά δεν
αλλάζει (αλλιώς προσαρμόζεται στα αποτελέσματα). Η ημερομηνία του commit είναι η απόδειξη.

Πρόταση για να αποφασίσει (όχι απόφαση):
> Συνεχίζουμε αν **οι ίδιοι ≥ 3 από τους 5** πληρούν **και τα δύο**: (α) δηλώνουν > 20 λεπτά για την τελευταία
> τους προσφορά **και** (β) απαντούν **ναι** στην πράξη. Μετράει ανά άτομο: 2 με (α) και άλλοι 2 με (β) = **όχι**.
> Αλλιώς σταματάμε ή αλλάζουμε πρόβλημα.
