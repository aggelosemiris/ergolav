# ergolav — Προσφορά επί τόπου

Ο τεχνίτης λέει στο κινητό τι χρειάζεται η δουλειά και βγαίνει έτοιμη προσφορά για τον πελάτη.

**Live:** https://aggelosemiris.github.io/ergolav/ (GitHub Pages — δημοσιεύεται από το `.github/workflows/pages.yml`· μία φορά: Settings → Pages → Source: «GitHub Actions»). Το `raw.githack.com` είναι μόνο για δοκιμές.

## Μικρόφωνο σε πραγματικό χρόνο

- **Φωνή → κείμενο**: Web Speech API (`SpeechRecognition`, `el-GR`) με ενδιάμεσα αποτελέσματα.
  Το κείμενο γράφεται όσο μιλάς (γκρι μέχρι να «κλειδώσει» η φράση).
- **Κυματομορφή**: πραγματική στάθμη ήχου από το μικρόφωνο (Web Audio `AnalyserNode`).
  Στο Android έχει απλό animation, γιατί δεύτερη πρόσβαση στο μικρόφωνο χαλάει την αναγνώριση.
- **Υλικά σε πραγματικό χρόνο**: όσο μιλάς, ο parser (`src/parse.js`) βρίσκει ποσότητες και υλικά
  του καταλόγου και τα δείχνει σαν τσιπάκια. Το «?» σημαίνει ότι λείπει επιλογή (π.χ. ποιο πλακάκι).
- Ακούει συνεχώς μέχρι να πατήσεις **Τέλος** (ξαναξεκινά μόνο του μετά από παύσεις).
  Μετά μπορείς να διορθώσεις το κείμενο με το χέρι ή να **συνεχίσεις να μιλάς**.
- Χωρίς υποστήριξη φωνής (π.χ. Firefox) ή χωρίς άδεια μικροφώνου: γράφεις το κείμενο.

## Φωτογραφία σημειώσεων

- **📷 Φωτογράφισε τις σημειώσεις σου** → ανοίγει η κάμερα → το Claude (`claude-sonnet-5-5`) ή το
  Google Gemini (`gemini-flash-latest`) διαβάζει τις σημειώσεις, και χειρόγραφες → οι γραμμές πάνε **κατευθείαν στον έλεγχο της προσφοράς**.
- Η φωτογραφία μικραίνει στο κινητό (≤ 1568px, JPEG) πριν σταλεί.
- Θέλει API key — Google (`AIza…`, δωρεάν επίπεδο με όρια, από aistudio.google.com) ή Anthropic
  (`sk-ant-…`). Η εφαρμογή καταλαβαίνει μόνη της ποιο είναι. Στο δωρεάν επίπεδο της Google τα
  δεδομένα μπορεί να χρησιμοποιηθούν για βελτίωση των υπηρεσιών της — για δοκιμές, όχι για πελάτες.
- Το key κρατιέται εξ ορισμού μόνο στη μνήμη της σελίδας (βλ. «Ασφάλεια & απόρρητο»).
  Η κλήση γίνεται απευθείας από τον browser (`dangerouslyAllowBrowser`) — κατάλληλο για
  προσωπική χρήση/δοκιμές· για πολλούς χρήστες χρειάζεται μικρός server που κρατά το key.
- Αν η ανάγνωση αποτύχει, μένει η φωτογραφία στην οθόνη και γράφεις τις γραμμές με το χέρι.
- Ενεργό είναι το server-side fallback (`fallbacks: "default"`): αν το μοντέλο αρνηθεί, ξανατρέχει σε άλλο.

## Τι μπαίνει στην προσφορά

**Μόνο υλικά του καταλόγου** (32 είδη, `src/catalog.js`). Ό,τι δεν βρίσκεται στον κατάλογο (π.χ. «κλιματιστικό») φαίνεται
στην οθόνη ελέγχου ως «Δεν υπάρχει στον κατάλογο — δεν μπαίνει στην προσφορά», δεν έχει πεδίο τιμής, δεν μπλοκάρει
τίποτα και δεν υπάρχει ούτε στα σύνολα ούτε στο PDF. Αν δεν βρεθεί κανένα υλικό του καταλόγου, δεν φτιάχνεται προσφορά.

## Τιμές υλικού και εργασία

- **Τιμή υλικού ανά γραμμή:** τρεις προτάσεις — **οικονομική**, **κανονική** (η τιμή του καταλόγου, προεπιλεγμένη:
  αν δεν αγγίξει τίποτα, η προσφορά βγαίνει όπως πριν), **ακριβή** — και **«Άλλη τιμή»** με ελεύθερο πεδίο.
  Οι συντελεστές (×0,6 και ×1,9 της κανονικής, στρογγυλεμένοι στα 10 λεπτά) είναι **προσωρινοί**: θα
  αντικατασταθούν από πραγματικές τιμές αγοράς. Η αρχική τιμή καταλόγου κρατιέται (`matBase`), ώστε οι
  προτάσεις να μη μετακινούνται όταν αλλάζει η επιλογή.
- **Μνήμη τιμών:** κάθε τιμή που γράφει ο τεχνίτης με «Κράτα την» αποθηκεύεται στη συσκευή (`localStorage`,
  `ergolav.prices`) ανά είδος + τύπο (η λεκάνη κρεμαστή δεν μπερδεύεται με τη λεκάνη δαπέδου): έως 3 τιμές, η
  πιο πρόσφατη πρώτη, με ημερομηνία. Εμφανίζονται **μόνο όταν πατηθεί «Άλλη τιμή»** και το πεδίο είναι άδειο·
  ποτέ δεν μπαίνουν μόνες τους. Τιμή παλαιότερη από 180 ημέρες γράφει «έλεγξε αν άλλαξε». Όσο είναι ανοιχτό το
  «Άλλη τιμή», το κουμπί της προσφοράς κλειδώνει. Η αποθήκευση δεν σπάει ποτέ την εφαρμογή (ιδιωτική
  περιήγηση, χαλασμένα δεδομένα → αγνοούνται). Όριο: ανά συσκευή, όχι ανά λογαριασμό· στο github.io το origin
  είναι κοινό για όλα τα repos του λογαριασμού (οι τιμές δεν είναι μυστικές).
- **Εργασία:** **ένα** πεδίο «Εργασία για όλη τη δουλειά», όχι ανά γραμμή. Προσυμπληρωμένο με την πρόταση του
  καταλόγου (Σ ποσότητα × εργασία του είδους)· ό,τι γράψει ο τεχνίτης μένει και δεν αλλάζει μόνο του όταν
  αλλάξουν ποσότητες — η πρόταση φαίνεται από κάτω για σύγκριση. Αυστηρή ανάγνωση αριθμών (το «1.500» μπλοκάρει
  και κλειδώνει το κουμπί). Μηδενίζεται σε κάθε νέα ανάλυση κειμένου. Το PDF δείχνει υλικό ανά γραμμή και την
  εργασία **μία φορά** στα σύνολα· οι γραμμές μόνο εργασίας (π.χ. αποξήλωση) γράφουν «στην εργασία».

## Αποστολή στον πελάτη

- Στην προεπισκόπηση φτιάχνεται **PDF (A4)** της προσφοράς (`src/share.js`, με το
  [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) — MIT, στο `vendor/`).
- **Στείλε στον πελάτη** → ανοίγει το μενού κοινοποίησης του κινητού (Viber, WhatsApp, email…) με το PDF
  και ένα σύντομο μήνυμα.
- Όπου ο browser δεν στέλνει αρχεία (π.χ. υπολογιστής): κατεβαίνει το PDF και ανοίγει WhatsApp/Viber/email
  με το μήνυμα, για να το επισυνάψεις.
- Η «υπενθύμιση σε 8 μέρες» δεν λειτουργεί ακόμα.

## Ασφάλεια & απόρρητο

- **API key:** εξ ορισμού μόνο στη μνήμη της σελίδας (ξεχνιέται όταν κλείσει). Αποθηκεύεται στη συσκευή μόνο αν
  ο χρήστης τσεκάρει «Να το θυμάται» — και **ποτέ** σε κοινόχρηστο domain (`raw.githack.com`, **`*.github.io`**,
  `pages.dev`, `netlify.app`, `vercel.app`…· εκεί σβήνεται και ό,τι είχε μείνει από παλιές εκδόσεις).
  Το `aggelosemiris.github.io` είναι κοινό origin για όλα τα repos του λογαριασμού, άρα το «Να το θυμάται»
  λειτουργεί **μόνο σε δικό μας domain**. Πεδίο κρυφό, «Ξέχασε το key» από την αρχική οθόνη.
  Για χρήση από τεχνίτες-πελάτες το σωστό είναι backend που κρατά το key (όχι key στο κινητό).
- **Φωτογραφία:** πριν σταλεί, οθόνη «Πριν σταλεί» όπου ο χρήστης καλύπτει **χειροκίνητα** με το δάχτυλο
  ονόματα/τηλέφωνα (δεν γίνεται αυτόματη ανίχνευση). Τα μαύρα ορθογώνια ζωγραφίζονται στα pixels του canvas πριν
  το base64, και το re-encode αφαιρεί EXIF/GPS — επιβεβαιωμένο από το `tests/browser/privacy.e2e.mjs`, που
  αποκωδικοποιεί τα bytes που στάλθηκαν. Η οθόνη λέει σε ποιον στέλνεται και τι κάνει με αυτή:
  Google δωρεάν επίπεδο → μπορεί να χρησιμοποιηθεί για βελτίωση και να τη δουν άνθρωποι (όχι στο πληρωμένο)·
  Anthropic → όχι για εκπαίδευση μοντέλων.
- **Κόστος:** Google Gemini έχει δωρεάν επίπεδο με όρια· Anthropic χρεώνει με προπληρωμένα credits
  (μοντέλο `claude-sonnet-5-5`, ~μισό κόστος από Opus).
- **Αριθμοί:** αυστηρή ανάγνωση (`src/number.js`): «1.234,50» = 1.234,50 €· αμφίσημα («1.234») ή άκυρα
  απορρίπτονται με μήνυμα, και κάτω από κάθε πεδίο φαίνεται πώς διαβάστηκε ο αριθμός. Ποτέ σιωπηλή τιμή.
- **ΦΠΑ:** ο τεχνίτης επιλέγει συντελεστή (24 / 17 / 13 / 9 / 6 / 4 / 0%). Η εφαρμογή **δεν προτείνει** ποιος
  ισχύει — ευθύνη του τεχνίτη / του λογιστή του. Τα 13% / 6% για ανακαινίσεις δεν έχουν ελεγχθεί.
- **Εξαρτήσεις:** όλος ο κώδικας σερβίρεται από τον ίδιο server (`vendor/`: Anthropic SDK 0.129.0,
  html2pdf.js — MIT). CSP: scripts μόνο από τον ίδιο server, δίκτυο μόνο προς Google Gemini / Anthropic.
  Εξωτερικό μένει μόνο το CSS/γραμματοσειρά Google Fonts (όχι κώδικας).
- **iframe:** το meta CSP **δεν** υποστηρίζει `frame-ancestors`. Γι' αυτό: έλεγχος σε JS (η εφαρμογή δεν τρέχει μέσα
  σε ξένο iframe) + αρχείο `_headers` με `frame-ancestors 'none'` για hosts που το διαβάζουν (Netlify/Cloudflare
  Pages). Το GitHub Pages αγνοεί το `_headers`.
- **Πηγές** για κάθε ισχυρισμό κόστους/απορρήτου/ΦΠΑ, με ημερομηνία ελέγχου: [`docs/SOURCES.md`](docs/SOURCES.md).

## Τρέξιμο

Το μικρόφωνο θέλει `https` ή `localhost`:

```sh
npm start        # http://localhost:8080
npm test         # unit tests (parser, αριθμοί, key) + holdout της QA (test/holdout-number.test.js)
npm run test:stress              # stress με mock provider
npm run test:stress:live:dry     # live harness χωρίς πραγματικές κλήσεις
```

Browser tests (Playwright + Chromium, δεν είναι dependency του project· θέλουν `npm start`):

```sh
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright/index.mjs CHROMIUM_PATH=/path/to/chromium node tests/browser/app.e2e.mjs
PLAYWRIGHT_MODULE=... CHROMIUM_PATH=... node tests/browser/privacy.e2e.mjs
```

Το `test/holdout-number.test.js` είναι ανεξάρτητο oracle της QA: δεν αλλάζουν οι αναμενόμενες τιμές για να περάσει ο κώδικας.

Στο κινητό: άνοιξε το live link παραπάνω.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Οθόνες και στυλ |
| `src/app.js` | Ροή: ακρόαση → διόρθωση → γραμμές → PDF → αποστολή |
| `src/mic.js` | Αναγνώριση φωνής + στάθμη ήχου |
| `src/number.js` | Αυστηρή ανάγνωση τιμών/ποσοτήτων (ελληνική γραφή) |
| `src/share.js` | PDF προσφοράς + αποστολή από το κινητό |
| `src/photo.js` | Φωτογραφία σημειώσεων → κείμενο (Gemini ή Claude) + διαχείριση key |
| `src/parse.js` | Ομιλία/σημειώσεις → γραμμές προσφοράς (ελληνικοί αριθμοί, μονάδες, επιλογές) |
| `src/catalog.js` | Κατάλογος 32 ειδών με ενδεικτικές τιμές αγοράς (εκτίμηση, χωρίς ΦΠΑ) |
| `src/prices.js` | Τρεις προτάσεις τιμής υλικού (οικονομική / κανονική / ακριβή) + μνήμη των τιμών που γράφει ο τεχνίτης |
