# ergolav — Προσφορά επί τόπου

Ο τεχνίτης λέει στο κινητό τι χρειάζεται η δουλειά και βγαίνει έτοιμη προσφορά για τον πελάτη.

**Live:** https://aggelosemiris.github.io/ergolav/

## Μικρόφωνο σε πραγματικό χρόνο

- **Φωνή → κείμενο**: Web Speech API (`SpeechRecognition`, `el-GR`) με ενδιάμεσα αποτελέσματα.
  Το κείμενο γράφεται όσο μιλάς (γκρι μέχρι να «κλειδώσει» η φράση).
- **Κυματομορφή**: πραγματική στάθμη ήχου από το μικρόφωνο (Web Audio `AnalyserNode`).
  Στο Android έχει απλό animation, γιατί δεύτερη πρόσβαση στο μικρόφωνο χαλάει την αναγνώριση.
- **Υλικά σε πραγματικό χρόνο**: όσο μιλάς, ο parser (`src/parse.js`) βρίσκει ποσότητες και υλικά
  του καταλόγου και τα δείχνει σαν τσιπάκια. Το «?» σημαίνει ότι λείπει επιλογή (π.χ. ποιο πλακάκι).
- Ακούει συνεχώς μέχρι να πατήσεις **Τέλος** (ξαναξεκινά μόνο του μετά από παύσεις).
  Μετά μπορείς να διορθώσεις το κείμενο με το χέρι ή να **συνεχίσεις να μιλάς**.
- Χωρίς υποστήριξη φωνής (π.χ. Firefox) ή χωρίς άδεια μικροφώνου: γράφεις το κείμενο.

## Φωτογραφία σημειώσεων

- **📷 Φωτογράφισε τις σημειώσεις σου** → ανοίγει η κάμερα → το Claude (`claude-opus-5-5`) ή το
  Google Gemini (`gemini-flash-latest`) διαβάζει τις σημειώσεις, και χειρόγραφες → οι γραμμές πάνε **κατευθείαν στον έλεγχο της προσφοράς**.
- Η φωτογραφία μικραίνει στο κινητό (≤ 1568px, JPEG) πριν σταλεί.
- Θέλει API key — Google (`AIza…`, δωρεάν επίπεδο με όρια, από aistudio.google.com) ή Anthropic
  (`sk-ant-…`). Η εφαρμογή καταλαβαίνει μόνη της ποιο είναι. Στο δωρεάν επίπεδο της Google τα
  δεδομένα μπορεί να χρησιμοποιηθούν για βελτίωση των υπηρεσιών της — για δοκιμές, όχι για πελάτες.
- Το key μπαίνει μία φορά και μένει μόνο στη συσκευή (`localStorage`).
  Η κλήση γίνεται απευθείας από τον browser (`dangerouslyAllowBrowser`) — κατάλληλο για
  προσωπική χρήση/δοκιμές· για πολλούς χρήστες χρειάζεται μικρός server που κρατά το key.
- Αν η ανάγνωση αποτύχει, μένει η φωτογραφία στην οθόνη και γράφεις τις γραμμές με το χέρι.
- Ενεργό είναι το server-side fallback (`fallbacks: "default"`): αν το μοντέλο αρνηθεί, ξανατρέχει σε άλλο.

## Αποστολή στον πελάτη

- Στην προεπισκόπηση φτιάχνεται **PDF (A4)** της προσφοράς (`src/share.js`, με το
  [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) — MIT, στο `vendor/`).
- **Στείλε στον πελάτη** → ανοίγει το μενού κοινοποίησης του κινητού (Viber, WhatsApp, email…) με το PDF
  και ένα σύντομο μήνυμα.
- Όπου ο browser δεν στέλνει αρχεία (π.χ. υπολογιστής): κατεβαίνει το PDF και ανοίγει WhatsApp/Viber/email
  με το μήνυμα, για να το επισυνάψεις.
- Η «υπενθύμιση σε 8 μέρες» δεν λειτουργεί ακόμα.

## Τρέξιμο

Το μικρόφωνο θέλει `https` ή `localhost`:

```sh
npm start        # http://localhost:8080
npm test         # tests του parser
```

Στο κινητό: άνοιξε το live link παραπάνω (GitHub Pages, Settings → Pages → Deploy from a branch → αυτό το branch, `/ (root)`).

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Οθόνες και στυλ |
| `src/app.js` | Ροή: ακρόαση → διόρθωση → γραμμές → PDF → αποστολή |
| `src/mic.js` | Αναγνώριση φωνής + στάθμη ήχου |
| `src/share.js` | PDF προσφοράς + αποστολή από το κινητό |
| `src/photo.js` | Φωτογραφία σημειώσεων → κείμενο (Claude vision) |
| `src/parse.js` | Ομιλία/σημειώσεις → γραμμές προσφοράς (ελληνικοί αριθμοί, μονάδες, επιλογές) |
| `src/catalog.js` | Κατάλογος ~35 υλικών/εργασιών με ενδεικτικές τιμές αγοράς (εκτίμηση, χωρίς ΦΠΑ) |

## Σημειώσεις

- Στο Chrome ο ήχος στέλνεται στην υπηρεσία αναγνώρισης της Google· στο Safari της Apple.
- Οι φωτογραφίες στέλνονται για ανάγνωση στην υπηρεσία του key (Google ή Anthropic).
